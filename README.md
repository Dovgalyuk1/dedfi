# DEDFI — the fund that never sells

Одностраничный лендинг мемкоина $DEDFI: пенсионный фонд, в который капает комиссия
с каждой покупки, покупает акции и никогда их не продаёт. Стаж холдера = выслуга лет.

## Что внутри
- статический `index.html` без сборки (инлайновые CSS и JS)
- `assets/` — четыре пиксельные стадии клерка, кропы, латунная табличка, фавикон
- мини-игра **THE RECORD BOOK**: 8 лет, каждый год приходит бумага с поводом продать,
  нужно успеть выбрать штамп HOLD среди подделок (SELL, HODL, H0LD, HOLD.) до таймера
- клерк стареет по ходу игры: NEW HIRE → ON THE BOOK → VETERAN → RETIRED
- Web Audio: офисный аккордеон с тиканьем настенных часов, звуки штампа/бумаги/монет

## Настройка перед листингом
В начале `index.html` блок SETTINGS:
```js
window.CONTRACT = "";   // адрес контракта
window.TWITTER  = "";   // ссылка на X
window.BUY_URL  = "";   // ссылка на покупку (пока пусто — кнопка неактивна)
```
